## The entry

One word — the word my ex would use to describe me:

> **archived**

Filed away like an old chat: still there, never opened again.

## How it works

`main.py` is a standard-library-only copier. It copies the pre-written
`entry.txt` into the output directory the harness provides
(`MAKEFUN_OUTPUT_DIR`), so the program's output is byte-identical on
every run.
